# 🖱️ Simple Auto Clicker

A lightweight and easy-to-use auto-clicker developed as a group project in collaboration with bubert-07, perw0l and cieba-uav.

Our goal is to create a simple tool that automates repetitive mouse clicking while gaining practical programming experience, improving our problem-solving skills, and learning how to collaborate effectively on a shared software project.

This project is also an opportunity to explore software development workflows, practice using Git and GitHub, and understand how individual contributions come together to create a working application.

## 📌 About the Project

The **Simple Auto Clicker** is a small software project focused on automating mouse clicks. Instead of repeatedly clicking the mouse manually, users will be able to start an automated clicking process and stop it whenever necessary.

The project is being developed for educational purposes as part of a collaborative effort between friends who want to improve their programming skills and gain hands-on experience with software development.

We believe that even a relatively simple application can be a great learning experience. By working on this project, we aim to understand the fundamentals of application development, write cleaner code, solve technical problems, and learn how to maintain a shared codebase.

As development continues, we plan to improve the application's functionality, usability, and overall reliability.

## 🎯 Project Goals

The main goals of this project are:

- **Learn programming:** Gain practical experience by developing a functional application.
- **Practice teamwork:** Collaborate with friends, share ideas, and divide development tasks.
- **Learn Git and GitHub:** Understand version control, commits, branches, and pull requests.
- **Improve problem-solving skills:** Identify bugs, troubleshoot errors, and find effective solutions.
- **Write better code:** Practice writing readable, maintainable, and well-organized code.
- **Understand software development:** Experience the process of planning, implementing, testing, and improving an application.
- **Build a useful tool:** Create a simple application that can automate repetitive mouse-clicking tasks.

## ✨ Planned Features

The following features represent the intended functionality of the project. Their availability depends on the current stage of development.

- **Automatic Mouse Clicking:** Automatically generate mouse clicks while the feature is active.
- **Start and Stop Controls:** Allow users to start and stop the clicking process whenever needed.
- **Configurable Click Interval:** Provide an option to adjust the time between consecutive clicks.
- **Simple User Interface:** Keep the application straightforward and easy to understand.
- **User-Friendly Controls:** Make the main functionality accessible without unnecessary complexity.
- **Future Improvements:** Leave room for additional features based on our experience, ideas, and feedback.

## 🔄 Development Workflow

To keep the project organized, we aim to follow a simple development workflow:

1. **Planning:** Discuss new features, improvements, and possible solutions.
2. **Implementation:** Write the code needed to introduce or improve functionality.
3. **Testing:** Check whether the application behaves as expected.
4. **Debugging:** Identify and fix errors discovered during development.
5. **Code Review:** Review changes and share feedback with other contributors.
6. **Integration:** Merge completed changes into the main project.
7. **Improvement:** Continue refining the application based on testing and experience.

This workflow helps us understand how software projects are managed in real-world development environments.
